## 核查方法

1. 以能執行 JavaScript 的瀏覽器實際載入現行官網，而非只讀原始 HTML。
2. 逐一切換：預設首頁、ApplePie ONE、ApplePie Touch、mini Ultra II、Melling／Melling-G、寄回總公司、390px 手機尺寸。
3. 比對目前官網 HTML 以及同網域載入的 `base.css`、`notice.css`、`faq.css`、`base.js`、`faq.js` 的實際內容與行為。
4. 修改 GitHub 的正式前端、純前端、同事展示前端與獨立 v6；將共同準備區塊與樣式改以官網現行檔案為基礎。
5. 使用獨立 Firefox/Playwright 瀏覽器直接讀取最新 GitHub 原始碼，以測試專用虛擬網站載入完整 HTML、CSS、JavaScript。測試不會修改正式官網或任何真實管理資料。

## 維護原則

正式官網是版型與既有流程的比對來源；已核准的新規格是差異的明確例外。官網更新後須重新查核差異，但**不得直接覆蓋 MG-only、Touch 單階段、指定升級韌體用語或取消下載前確認視窗等已定案內容**。

此次只修改 GitHub 預覽／交付程式碼，**沒有操作正式 NAVLYNX 官網**，也沒有將密碼、TOTP 密鑰或資料庫放入 GitHub。
