# NAVLYNX Android 16 公告系統

本目錄用於同事預覽與網頁公司交接，不修改既有 `navlynx-android16-preview/`。

## 版本區分

- `demo/`：同事互動展示，無正式登入、無伺服器寫入；所有「儲存／發布」只在目前瀏覽器模擬。
- `fullstack/`：正式前台＋後台原始碼，部署到 Python 主機後才可使用真實登入與發布。
- `frontend-only/`：純前台版本，公告由網頁公司維護設定檔。

## 管理帳號

預定帳號為 `navlynx.applepie@gmail.com`，這是本公告後台的帳號識別，不是 Google 或 Gmail 登入。
沒有預設密碼，也未在此 GitHub 頁面建立正式帳號。部署者須在受信任的伺服器終端執行初始化，由帳號持有人設定獨立密碼並完成驗證器綁定。

手機驗證採 TOTP 驗證器 App 六位數動態碼，不是簡訊。正式後台每次登入需要密碼與驗證碼；展示頁不蒐集這些資料。

**禁止提交 `.env`、資料庫、密碼、TOTP 密鑰、Cookie、備份或任何真實驗證資訊。**

展示頁不等於正式主機。正式 HTTPS、主機防護、最新依賴弱點掃描、帳號建立及手機綁定須由部署流程完成。
